# Security Policy

## Supported versions

Only the current default branch is supported.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues. Contact [rosch100 on GitHub](https://github.com/rosch100) or use the repository's [private security advisory page](https://github.com/rosch100/Amazon-MoneyMoney/security/advisories/new) when available. Include the affected file or version, reproduction steps, and impact. Do not include real credentials, session cookies, or personal data.

Reports are acknowledged as soon as practical and evaluated before a fix or mitigation is published.
